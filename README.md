# ResumeGo

**ResumeGo** is a free, web-based resume builder that lets users create, edit, and download professional resumes using polished templates — all from their browser.

Live Demo: https://resumego.netlify.app/

---

## 🎯 Features

- Create a new resume from scratch using a clean and intuitive UI  
- Select from professional templates  
- Edit different resume sections (e.g. Personal Info, Education, Work Experience, Skills, etc.)  
- Live preview of your resume  
- Download resume as PDF  
- User sign-in / account management (if implemented)  
- Responsive design (usable on desktop, tablet, mobile)

##🚀 Usage

Click “Create New Resume” to start from a blank template

Fill in your details section by section

Use “Templates” to switch visual styles

Preview the output in real time

When done, click “Download” to get a PDF version
